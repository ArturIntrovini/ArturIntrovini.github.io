Privacy policy

Last updated: 3 October 2026

Who uses this app

Leo BOTrato is used only by its owner, to manage their own YouTube channel, @LeoBotrato. Nobody else signs in to it.

What it accesses

With the owner's permission, it uses the YouTube Data API to create live broadcasts on that channel and to change their titles, descriptions, visibility, and playlists. It does not read, collect, or store data about viewers or about any other Google account.

How it is stored

The sign-in token is stored only on the owner's private server. It is not shared with anyone or used for any other purpose. The owner can revoke it at any time at myaccount.google.com/permissions.

Google API Services

Leo BOTrato's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
